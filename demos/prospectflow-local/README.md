# ProspectFlow Local

ProspectFlow Local is a customer-facing portfolio demo for agencies, consultants, and lead-gen operators who need a sharper way to find and prioritize local-business opportunities. The app frames prospecting as revenue software: pick a market, score the right accounts, and move directly into outreach with visible commercial context.

## Target buyer

- Boutique agencies selling web, SEO, CRO, or local-growth work
- Freelancers packaging local prospecting into a repeatable service
- Operators who want a vertical-specific sales layer instead of flat lead lists

## What it shows

- Search controls for city, niche, and opportunity type
- Ten plausible leads with scores, site gaps, and monthly value ranges
- Detail panel explaining why each account matters now
- Concrete quick wins and contact-ready outreach angles
- Pipeline counts and a clear path to a commissioned custom build

## Local run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run build
npm run lint
```

## Customization ideas
